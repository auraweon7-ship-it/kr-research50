# 대한민국 연구 50년

국가 R&D 및 학술·인재양성 투자의 장기 파급효과를 추적하는 웹 플랫폼 시안입니다.
한국연구재단 50년 대표 성과 50선과 대표 연구자 50인의 발굴 체계, 영향경로, 기여도 분석, 대국민 확산 기획을 한 곳에서 보여줍니다.

> **데이터 안내**
> 발굴체계·세부기준·일정은 연구계획서의 제안값(안)입니다.
> 성과·연구자 후보, 점수, 투입액, 기여 비중은 화면 시연용 예시 데이터이며 실제 선정 결과가 아닙니다.
> 성과 후보는 일반 주제어, 연구자 후보는 익명 ID(`R-001` 등)로 표기합니다.

## 화면 구성

| 번호 | 메뉴 | 내용 |
|---|---|---|
| 01 | 사업 목표 | 추진배경, 단기 성과관리의 한계, 연구 필요성·목적, 산출물·정량 목표, 4대 추진전략과 8개월 로드맵, 기대효과 |
| 02 | 성과 발굴체계와 기준 | 5대 투입요소 × 5개 지원영역 포트폴리오, 체계 모듈 S1~S6, 세부기준 C1~C6, 50년 시대 구간, 투웨이 하이브리드, 6대 가이드라인·가중치, 선정 절차 |
| 03 | 대표 성과 50선 | 후보 검색·필터, 4단계 영향경로, 단계별 기여 구성, 스토리텔링 모델 |
| 04 | 대표 연구자 50인 | 후보 검색·필터, 생애주기 성장 흐름, 연계 성과 |
| 05 | 정부 지원 기여도 분석 | 기여분석 6단계, 기여 강도 4등급, 투자 대비 성과 지수, 심층 인터뷰·검증 설계 |
| 06 | 대국민 확산자료 기획 | 통합 웹플랫폼, 백서 2종, 홍보 책자, AI 모션그래픽 영상·인포그래픽, 시각화 10종, 확산 채널 |

주요 상호작용

- 후보 상세에서 검증 단계(후보 → 심층검토 → 선정위 상정 → 최종선정)를 지정하면 모든 화면의 집계에 반영되고 브라우저에 저장됩니다.
- 세부기준 가중치를 조정하면 성과 점수와 투자 대비 성과 지수, 순위가 즉시 다시 계산됩니다.
- 최종선정 결과를 JSON으로 내보낼 수 있습니다.

## 실행

빌드 과정이 없는 정적 사이트입니다. 폴더를 로컬 서버로 띄우면 됩니다.

```bash
python -m http.server 5178
```

브라우저에서 `http://localhost:5178` 을 엽니다. `index.html` 을 직접 열어도 동작합니다.

## 파일 구조

```
index.html          진입 페이지
assets/
  style.css         뉴모피즘 스타일, 반응형 레이아웃
  app.js            화면 렌더링과 상호작용
  content.js        연구계획서 기반 문안(체계·기준·일정·산출물)
  data.js           예시 후보 데이터 생성(성과·연구자·투입 포트폴리오)
```

문구를 고칠 때는 `content.js`, 실제 과제·수혜 이력 데이터를 연결할 때는 `data.js` 의 `OUTCOMES`, `PEOPLE`, `PORTFOLIO` 를 교체합니다.

## 투자 대비 성과 지수(안)

```
투자 대비 성과 지수 = 표준화 성과 점수 × 기여 계수 ÷ 실질 투입 지수(로그 척도)
```

기여 계수는 기여 강도 4등급(결정적 1.0, 핵심 0.7, 보완 0.4, 간접 0.2)을 따릅니다. 산식과 계수는 제안값이며 기준 세미나와 선정위원회에서 확정합니다.

## 기술

외부 라이브러리 없이 HTML, CSS, JavaScript만 사용합니다. 차트는 인라인 SVG로 그립니다. 글꼴은 Pretendard를 CDN에서 불러옵니다.
