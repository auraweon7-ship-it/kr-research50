# 대한민국 연구 50년

국가 R&D 및 학술·인재양성 투자의 장기 파급효과를 추적하는 웹 플랫폼 시안입니다.
한국연구재단 50년 대표 성과 50선과 대표 연구자 50인의 발굴 체계, 영향경로, 기여도 분석, 홍보 확산 기획을 한 곳에서 보여줍니다.

> **데이터 안내**
> 발굴체계·세부기준·일정은 연구계획서의 제안값(안)입니다.
> 성과·연구자 후보, 점수, 투입액, 기여 비중은 화면 시연용 예시 데이터이며 실제 선정 결과가 아닙니다.
> 성과 후보는 일반 주제어, 연구자 후보는 익명 ID(`R-001` 등)로 표기합니다.
> 실제 후보는 "연구 관리 → 데이터 관리" 에서 CSV·엑셀로 가져와 예시 옆에 추가할 수 있습니다.

### 공개용과 연구용

사이드바에서 전환합니다. 공개용은 최종선정된 성과·연구자만 보이고 점수·검증 단계·근거 패키지·관리 도구를 감춥니다. `localhost` 에서는 연구용이, 배포 주소에서는 공개용이 기본입니다.

**연구 관리(08)** 는 관리자 모드에서만 보입니다. 화면 오른쪽 위 자물쇠를 눌러 로그인하며, 로그인은 그 탭을 닫을 때까지 유지됩니다. 암호는 `config.js` 에 SHA-256 해시(`ADMIN_HASH`)로만 두었습니다.

`config.js` 의 `STAFF_PASSCODE` 는 간이 잠금입니다. 관리자 로그인과 간이 잠금 모두 브라우저 안에서만 확인하므로 화면을 가리는 용도이며 **보안 수단이 아닙니다.** 실제로 내부 화면을 막으려면 서버 쪽 로그인이 필요합니다.

### 연구 관리 도구

- **데이터 관리** — CSV(UTF-8·CP949)·TSV·엑셀을 올리거나 표를 붙여넣어 후보를 가져옵니다. 양식 내려받기, 미리보기와 오류 행 표시, 전체 백업·복원을 제공합니다.
- **근거 패키지** — 후보 상세에서 근거문헌(유형·제목·링크·메모)을 등록하면 "2건 이상 확인" 기준을 자동 판정합니다.
- **선정위 심의** — 후보를 최대 3건 나란히 비교하고, 위원 5인의 평점·의견·이해충돌을 기록해 회의록 초안을 만듭니다.
- **균형 점검** — 영역별 배분(표 2-9)과 시대 구간 최소 기준을 현재 선정과 대조하고, 부족한 영역의 보충 후보를 보여줍니다.
- **민감도 분석** — 가중치와 기여 계수를 무작위로 흔들어 400회 다시 계산하고, 순위 변동 범위와 경계 후보를 보여줍니다.
- **인터뷰 관리** — 대상·일정·동의·진행 상태·요지·주제 코딩을 기록합니다. 요지는 후보 상세의 인터뷰 발췌에 표시됩니다.

## 실행

빌드 과정이 없습니다. 함께 들어 있는 `server.js` 가 화면 파일을 내주고 학술 API 요청을 중계합니다(의존성 없음, Node 18 이상).

```bash
npm start
```

브라우저에서 `http://localhost:5178` 을 엽니다. 포트는 `PORT` 환경변수로 바꿉니다.
`python -m http.server` 같은 정적 서버로도 화면은 뜨지만, 그 경우 데이터 검색에서 국내 API(NTIS·KCI·RISS·KRM)는 쓸 수 없습니다.

## 데이터 검색 (10)

| 출처 | 키 | 호출 방식 |
|---|---|---|
| OpenAlex | 선택 | 브라우저에서 직접. 한국연구재단 지원 필터와 과제번호 제공 |
| Crossref | 없음 | 직접. 연구비 기관 정보 |
| NCBI PubMed | 선택 | 직접 |
| Semantic Scholar | 선택 | 중계 서버가 있으면 경유. 키가 없으면 요청 한도가 매우 낮음 |
| Scopus | 필수 | 직접. 기관 구독 키 필요 |
| NTIS · KCI · RISS · KRM | 필수 | 중계 서버 경유 (브라우저 직접 호출을 막는 API) |

- **API 설정**에서 출처별 키와 요청 주소를 입력합니다. 주소의 `{q}`·`{key}`·`{n}`·`{from}`·`{to}` 가 검색어·키·건수·연도로 바뀝니다. 국내 API 기본 주소는 공개 문서 기준 예시이고, KRM은 공공데이터포털에서 받은 주소를 넣어야 합니다.
- **직접 API 추가**로 JSON·XML API를 더 붙일 수 있습니다. 중계 서버를 거치려면 그 호스트를 `PROXY_HOSTS` 환경변수(쉼표 구분)에 추가해야 합니다.
- 결과는 DOI 또는 제목·연도로 중복을 합치고, 연도별 분포·저자·학술지·분야 순위·피인용 상위로 분석합니다. CSV로 내려받거나 골라서 역방향 트랙 성과 후보로 보낼 수 있습니다.
- API 키는 그 브라우저(localStorage)에만 저장되고 공유 저장소나 저장소 파일에 들어가지 않습니다.

중계 서버(`/proxy`)는 허용한 호스트만 통과시키고, 접속 주소당 분당 120회로 제한합니다. 오류 응답에 되돌아온 API 키는 화면에서 가립니다.

### 분석 도구 (데이터 검색의 하위 화면)

| 화면 | 하는 일 |
|---|---|
| 통합 검색 | 여러 출처 검색, 더 가져오기(출처별 다음 쪽), 공저 네트워크, 검색 저장과 다시 실행(새 결과 표시) |
| 과제 역추적 | 재단 과제번호로 그 과제를 단 논문을 모두 찾고, NTIS 키가 있으면 과제 정보를 함께 찾음. 후보 근거로 붙이거나 성과 후보로 추가 |
| 연구자 이력 | 저자 이름·ORCID로 연도별 논문·재단 지원 논문·피인용을 모아 첫 지원 연도와 전환점을 추정. 인물 후보로 추가 |
| 지원 효과·추이 | 같은 주제에서 재단 지원 논문과 그 밖의 논문을 비교(피인용, FWCI, 상위 10% 비율; 각 200편 무작위 표본)하고, 연도별 전체 추이와 재단 지원 비중을 집계 |

후보 상세 화면의 근거 패키지에는 "외부 데이터로 확인" 버튼이 있어(관리자 모드) OpenAlex에서 관련 논문을 찾아 근거로 바로 붙일 수 있습니다.

### 서버 공용 API 키

연구진이 각자 키를 넣지 않아도 되도록 서버 환경변수에 키를 둘 수 있습니다.

```
KEY_NTIS, KEY_KCI, KEY_RISS, KEY_KRM, KEY_KIPRIS, KEY_SCOPUS, KEY_S2, KEY_OPENALEX, KEY_NCBI
KEY_BIGKINDS, KEY_NANET, KEY_NTB, KEY_KIPRISC   (파급 근거 자료원, 선택)
ANTHROPIC_API_KEY  결과보고서 AI 구조화·원고 초안·보도자료 (없으면 그 기능만 꺼짐)
AI_MODEL      AI 모델 (기본 claude-opus-5-5, 거절 시 서버 쪽 대체 모델 사용)
DATA_DIR      서버 저장소 폴더 (기본 ./data — Railway에서는 볼륨을 여기에 붙이기)
WATCH_DAYS    자동 추적 주기(일, 기본 30)
AUTH_SECRET   세션 서명 키 (권장. 없으면 서버를 다시 시작할 때마다 다시 로그인)
ADMIN_HASH    관리자 암호 해시 (없으면 config.js 값)
```

서버 키는 관리자 로그인으로 받은 서버 세션(HttpOnly 쿠키, 12시간)이 있는 요청에만 쓰이고, 브라우저에는 키 값이 전달되지 않습니다. 원본 응답에 키가 되돌아오면 서버가 가린 뒤 보냅니다. 로그인 시도는 분당 10회로 제한합니다.

### 연결 자료 (데이터 검색 → 연결 자료)

통합 검색 결과에서 자료를 골라 대표 성과·대표 연구자 항목을 지정하고 "항목에 연결"을 누르면 그 항목에 쌓입니다. 구분(성과: 핵심 성과·후속 성과·파급·활용·근거 문헌·관련 연구 / 연구자: 대표 업적·공동연구·지원 과제 성과·후속세대·관련 연구)과 메모를 달 수 있고, 같은 자료는 중복으로 넣지 않습니다. 각 항목 상세 화면(관리자)에서 연결 자료 목록·요약(연도 범위, 피인용 합계, 재단 지원 건수)을 보고 구분 변경·해제·근거 패키지 등록·CSV 내려받기를 합니다. "연결 자료" 화면은 100개 항목의 연결 현황을 한눈에 보여 줍니다. 저장은 `db.data.linked`(공유 저장소 사용 시 `linked` 행)입니다.

### 이력 타임라인 (성과·연구자 상세)

각 상세 화면에 가로 시간축 타임라인이 있습니다. 시대 구간(Ⅰ~Ⅴ) 위에 지원 단계(성과: 기초·원천연구 → 산업·사회 활용 / 연구자: 생애주기 단계와 전환점), 연계 연구자·연계 성과를 줄로 놓고, 관리자 모드에서는 데이터 검색으로 연결한 자료를 구분별 줄에 피인용 크기의 점으로 더합니다(재단 지원 자료는 진한 테두리). 아래에는 연도별 건수 막대와 누적 자료 수(실선)·누적 피인용(점선) 성장 곡선이 그려지고, 첫 지원부터 첫 성과까지 걸린 해, 정점 연도, 최근 5년 비중, 재단 지원 뒤 이어진 자료 수를 요약합니다.

| ④ 식별·정제 | 이름·연구자번호·소속으로 연구자 묶기, 동명이인 판정, ORCID 찾기, 과제번호·제목 기준 중복 합치기, 통합 전·후 사업코드 매핑표 |
| ⑤ 재단 DB 대조 | 재단 추출본과 과제고유번호로 대조 — 일치율, 재단에만 있는 과제(보완 추가), 항목 불일치 |
| ⑥ 후보군 풀 | 영역·시대별 성과·인물 후보(목표 각 300건, 정방향·역방향), 확정 시 데이터 관리로 보내기, 출처 문구 |
| 수집 로그·출처 | 수집 일시·검색식·건수, 30일 넘은 계획의 월간 갱신 알림, 자료원별 이용조건 편집 |

수집 자료는 수천 건이 될 수 있어 이 브라우저의 IndexedDB(`nrf50-pool`)에 저장합니다. NTIS·KRM·KIPRIS 응답 구조는 기관 안내에 따라 다를 수 있으므로 첫 수집 뒤 '항목 대응 확인'에서 맞춰 주세요. AI 구조화는 서버 `/ai/extract`(관리자 세션 필요)를 거치며 server-side fallback 베타가 켜져 있습니다.

## 역할과 계정

| 역할 | 할 수 있는 일 |
|---|---|
| 관리자 | 전체 + 계정 관리·서버 백업 (암호만 넣고 로그인) |
| 연구진 | 관리 도구 전체(데이터 검색·모집단·분석·AI·편집) |
| 선정위원 | 사업 진척, 선정위 심의, 검증 흐름 승인·수정 요청 |
| 재단 담당자 | 사업 진척·검증·품질·연구자 입력 현황 열람 |

계정은 연구 관리 → 계정·감사에서 관리자가 만들고(암호는 서버에 scrypt 해시로 저장), 로그인 창에 아이디와 암호를 넣습니다. 모든 서버 쓰기는 감사 로그에 누가·언제·무엇을 했는지 남습니다.

## 서버 저장소와 공개 API (npm start)

Supabase를 쓰지 않으면 플랫폼 서버가 `DATA_DIR`(기본 `./data`, 저장소에는 올리지 않음)에 JSON으로 저장하고, 연구진이 같은 상태를 봅니다. 공개 화면에 필요한 값(검증 단계 등)만 로그인 없이 읽힙니다. **Railway에서는 볼륨을 DATA_DIR에 붙여야 다시 배포해도 자료가 남습니다.**

- `/api/state` 공유 상태 · `/api/kv/pool|poolmeta|poollog` 모집단 · `/api/users` 계정 · `/api/audit` 감사 로그 · `/api/backup` 전체 백업
- `/api/forms/…` 연구자 입력 링크(서명 토큰, 기한) · `/api/watch`·`/api/alerts` 자동 추적(30일마다 OpenAlex) · `/api/vote`·`/api/cheer` 국민 참여(횟수 제한, 응원은 승인 후 게시)
- `/api/open/outcomes.json|csv`, `/api/open/people.json|csv` 오픈 데이터(CC BY 4.0, CORS 허용) · `/s/O-001` 공유 미리보기 · `/api/ai/write` 원고 초안·보도자료

## 분석 도구 (상세 화면, 관리자·연구진)

- **실데이터 점수 제안** — 연결 자료의 피인용·기간·구분·출처·재단 지원·활용 자료로 세부기준 4개 점수를 제안하고, 적용하면 순위·지수에 반영(되돌리기 가능)
- **인용 사슬 복원** — 연결 논문(DOI)을 인용한 논문의 연도 분포, 인용 기관 유형, 인용한 기업·정부기관, 많이 인용된 후속 논문(OpenAlex)
- **원고 초안·보도자료·영문 요약(AI)** — 근거 패키지·연결 자료·인터뷰 메모·사실 목록만 근거로 쓰고 문단마다 근거 번호. 근거 점검이 근거 없는 문단과 근거에 없는 수치를 표시. 상태(초안·검토 중·확정)
- **검증 흐름** — 작성 중 → 검토 요청 → 승인(또는 수정 요청), 단계 이력 기록
- **짝지은 비교**(데이터 검색) — 한국 기관 논문 중 재단 지원·비지원을 연도·세부분야로 층화해 피인용·FWCI 비교, 부트스트랩 95% 구간

## 저장소

기본은 각자의 브라우저(localStorage)에 저장합니다. 연구진이 같은 내용을 보려면 플랫폼 서버 저장소(위)나 Supabase를 씁니다.

1. Supabase 프로젝트의 SQL 편집기에서 `supabase/schema.sql` 을 실행합니다.
2. `assets/config.js` 의 `SUPABASE_URL`, `SUPABASE_ANON_KEY` 를 채웁니다.

검증 단계, 근거 패키지, 심의 기록, 인터뷰, 가져온 데이터가 공유됩니다. 나중에 저장한 쪽이 반영됩니다.
`schema.sql` 의 기본 정책은 키를 가진 누구나 읽고 쓸 수 있으므로, 공개 배포에서는 로그인(Supabase Auth)을 붙이고 정책을 바꾼 뒤 쓰십시오.

## 그 밖의 기능

- **통합 검색** — 사이드바 입력창 또는 `/` 키. 성과·연구자·메뉴·구역을 함께 찾습니다.
- **영문 전환** — 메뉴, 라벨, 유형, 성과명, 분야를 영어로 바꿉니다. 긴 설명문과 그림 속 글자는 한국어로 남는 부분 번역입니다.
- **접근성** — 본문 건너뛰기, 키보드 초점 표시, 상세 창 초점 가두기, 표 머리글 지정, 그래프의 키보드 조작과 표 대안, 움직임 줄이기 설정 반영, 보조 글자색 대비 조정. 자동 점검 도구나 사용자 평가로 KWCAG 적합성을 확인한 것은 아닙니다.
- **연구 네트워크 그래프** — 배치 4종(힘 배치·원형(영역별)·시간축(첫 지원 연도×영역 줄)·영역 군집)을 노드가 미끄러져 옮겨 가는 전환 모션으로 바꾸고, 곡선 연결(계보 연결은 흐르는 점선)·영역 구름(숨 쉬는 빛)·선택 시 이웃으로 번지는 파동·호버 확대·선택 이웃만 보기·허브 자동 투어(연결 많은 노드를 4초마다 따라감)·라벨(자동/모두/끄기)·밝은/어두운 배경을 고릅니다. 노드를 누르면 그 곁에 Remotion 모션 팝업(숫자 카운트업·단계 선·이웃만/경로/상세 버튼)이 떠서 노드를 따라다니고 점선 연결선으로 이어집니다(Esc로 닫기). 크기: 그래프 높이(360~1100px, S·M·L·XL), 노드 크기(50~220%), 글자 크기(9~18px), 확대·축소·맞춤 버튼 — 선택은 이 브라우저에 기억합니다.
- **인포그래픽 데이터 수집·갱신** — 데이터 검색 → 인포그래픽 데이터에서 항목을 고르고 '수집'하면 연결 자료(논문 수·피인용), 모집단 구축에서 그 항목에 연결한 과제·성과(첫 지원 연도·사업·과제 수·연구비·특허·기술료, 과제고유번호로 이어진 성과 포함), OpenAlex 저자(연구자: 논문 수·피인용·h-지수·공저자)에서 값을 모아 지금 값과 나란히 보여 줍니다. 골라서 반영하면 인포그래픽·카드·상세·타임라인에 함께 적용되고(예시 값은 보관, '반영 지우기'로 복원), 인포그래픽의 '데이터 갱신'은 바뀐 값을 한 번에 반영합니다. 모집단 구축 → ⑦ 인포그래픽 연결에서 과제·성과를 대표 항목에 연결합니다. 반영한 숫자·연도(infoData)는 공개 화면에도 쓰이고, 관련 성과 제목 목록(infoOut)은 로그인한 연구진만 봅니다.
- **카드 하단 관련 성과 표** — 대표 성과·연구자 카드마다 연도·구분·성과 표. 수집한 관련 성과가 있으면 최근 순 3건(외 n건), 없으면 영향경로 단계별 산출물(성과)·연계 대표성과와 누적 실적(연구자).
- **성과 확산 지도** — 지원 영역·생활 분야·출발 시대 필터와 검색, 표지 색 기준(지원 영역·생활 분야·확산 단계), 1977~2026년 '50년 재생'(해마다 첫 지원 성과가 나타나고 단계에 따라 표지가 커짐), 권역 요약(성과·최종선정·평균 확산·활용 도달)과 누적 추이, 권역 원 켜기·끄기, 조건별 CSV. 모션: 지도에 다가가며 성과가 첫 지원 연도 순으로 떠오르고, 확산 단계가 오를수록 표지가 커지며(활용 단계는 빛남, 최종선정은 고리 파동), 재생 중 단계가 오르는 순간 파동이 터지고, 권역마다 성과 수에 비례한 확산 파동이 퍼집니다. 계보·연구자 공유로 이어진 성과 사이에 위로 솟는 지식 흐름선과 흐르는 입자를 그리고(켜기·끄기), 표지를 누르면 이어진 흐름선이 자라나며 연결된 성과로 파동이 번집니다. 연도 표시판·진행 막대·권역 숫자·추이선도 움직입니다(동작 줄이기 설정 시 정지). Google 지도를 못 쓰면 권역 도해(점이 도는 모션)로 대체합니다.
- **카드 뉴스 장수** — 세트당 카드를 3~8장으로 고릅니다(표지·시작·경로·확산(전환점)·기여 변화(역할 변화)·숫자로 보기·평가(성과 이력)·맺음 중 우선순위대로). 선택은 이 브라우저에 기억합니다.
- **카드 뉴스 MP4** — 고른 장수의 카드를 이어 붙인 세로 영상(장당 5초, 1080×1920, H.264)을 브라우저에서 만듭니다. WebCodecs를 지원하는 Chrome·Edge에서 동작합니다.
- **대표성과 인포그래픽** — 한 줄 요약, 50년 시간축과 단계 간 시차, 단계별 정부 비중 변화, 영역 내 점수 분포, 연계 연구자 파급 합계를 더했고, 화면에 들어오면 숫자 올라가기·선 그리기·막대 차오르기·차례로 떠오르기 모션이 재생됩니다(동작 줄이기 설정 시 정지). 성과별 단독 HTML(스타일·모션 포함) 또는 50선 HTML ZIP으로 내려받습니다.

## 투자 대비 성과 지수(안)

```
투자 대비 성과 지수 = 표준화 성과 점수 × 기여 계수 ÷ 실질 투입 지수(로그 척도)
```

기여 계수는 기여 강도 4등급(결정적 1.0, 핵심 0.7, 보완 0.4, 간접 0.2)을 따릅니다. 산식과 계수는 제안값이며 기준 세미나와 선정위원회에서 확정합니다.
